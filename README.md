# TinyLink – URL Shortener (Next.js + Neon Postgres)

TinyLink is a minimal, production-ready URL shortener similar to Bitly.  
You can create short URLs, track clicks, view stats, and manage links.

---

## 🚀 Features

- Create short URLs with optional custom codes  
- 302 redirects  
- Click tracking + last clicked timestamp  
- Dashboard with full CRUD  
- Stats page: `/code/:code`  
- Health check: `/healthz`  
- API endpoints  
- Fully responsive, clean UI  
- Uses Neon Postgres + Prisma  
- Deployed on Vercel (recommended)

---

## 📦 Tech Stack

- Next.js 14 (App Router)
- TailwindCSS
- Neon Postgres
- Prisma ORM
